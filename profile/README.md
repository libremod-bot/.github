## 👋 Hallo!

Wir bauen **Libremod**, einen Discord-Bot, der Moderation, Community und Verwaltung an einem Ort vereint. Ohne Premium-Stufen, ohne Limits zum Freikaufen und ohne dass deine Daten irgendwo anders landen als auf deinem eigenen Server.

<table>
<tr>
<td width="33%" valign="top">

#### 💸 Wirklich frei
Alle Funktionen sind für jeden Server freigeschaltet. Kein „Upgrade für 4,99 € im Monat“, heute nicht und auch nicht später.

</td>
<td width="33%" valign="top">

#### 🏠 Deine Daten, dein Server
Libremod läuft bei dir. Keine Telemetrie, kein zentraler Dienst, keine Werbung. Niemand außer dir sieht, was auf deinem Server passiert.

</td>
<td width="33%" valign="top">

#### ⚡ Schnell startklar
Ein Install-Skript richtet Bot, Datenbank, Dashboard, HTTPS und Sicherungen ein. Updates per Knopfdruck im Dashboard.

</td>
</tr>
</table>

## ✨ Was Libremod kann

| | |
|---|---|
| 🛡️ **Schutz** | Moderation mit Fallakte, Auto-Mod, Anti-Phishing, Raid-Schutz, Verifizierung, Lockdown, Logging |
| 💬 **Community** | Begrüßung mit Bild, Rollen per Knopf, Tickets, eigene Befehle, Benachrichtigungen für YouTube, Twitch und mehr |
| 🎉 **Spaß** | Level mit Rang-Karte, Server-Währung mit Shop, Gewinnspiele, Events, Umfragen, Geburtstage |
| ⚙️ **Verwaltung** | Web-Dashboard mit Einrichtungs-Assistent, Team-Zugänge, Änderungsprotokoll mit Rückgängig, Statistik |

## 🚀 Loslegen

Du brauchst nur einen kleinen Linux-Server (Debian oder Ubuntu, 1 GB RAM, sogar ein Raspberry Pi reicht):

```bash
curl -fsSL https://raw.githubusercontent.com/libremod-bot/libremod/main/deploy/install.sh -o install.sh
sudo bash install.sh
```

Die Schritt-für-Schritt-Anleitung mit Screenshots findest du in **[SELBSTHOSTEN.md](https://github.com/libremod-bot/libremod/blob/main/docs/SELBSTHOSTEN.md)**.
